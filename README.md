# 민한이 성장일기 👶💬

민한이(2016년 2월 22일 오전 11시 55분생)가 한 말을 날짜별로 기록하고 다시 보는 앱입니다.

## 기능

- **오늘**: 탄생 며칠째인지(태어난 날 = 1일째, 백일 = 100일째), 만 나이, 태어난 뒤 흐른 시간, 다음 기념일(100일 단위, 1000일 단위, 생일)까지 D-day
- **쓰기창**: 날짜별로 민한이가 한 말과 상황 메모, 시간을 적어 둡니다. 기록을 누르면 고치거나 지울 수 있어요.
- **달력**: 기록이 있는 날에 점이 찍힙니다. 날짜를 누르면 그날 한 말이 보여요.
- **지난해 오늘**: 예전 같은 날짜에 한 말을 보여 줍니다.
- **찾기**: 단어로 검색하고, 전체 기록을 JSON 파일로 백업받을 수 있어요.
- **가져오기**
  - **캡쳐 사진**: 텔레그램 대화 캡쳐에서 글자를 읽어(OCR, 한국어) 말풍선 단위로 나눕니다. 왼쪽/오른쪽 말풍선을 따로 고를 수 있고, 캡쳐에 날짜 구분선(예: "11월 13일")이 있으면 그 날짜를 씁니다.
  - **텔레그램 봇**: 봇에게 보내거나 봇이 초대된 방의 메시지가 '받은 메시지함'에 모입니다. 민한이가 한 말만 골라 일기로 옮기세요.
    - `민한: 할 말`, `#민한 할 말`, `/m 할 말` 처럼 보내면 바로 저장됩니다.
    - 다른 사람의 메시지를 봇에게 **전달**하면 원래 보낸 사람과 보낸 날짜가 그대로 남아요.
    - 캡쳐 사진을 봇에게 보내면 앱에서 글자를 읽어 옮길 수 있어요.
  - **대화 내보내기 파일**: 텔레그램 PC 앱의 "대화 내보내기(JSON)"로 받은 `result.json` 파일에서 골라 옮길 수 있어요. 지난 대화를 한꺼번에 가져올 때 좋습니다.

## 실행

Node.js 22.9 이상만 있으면 됩니다. 따로 설치할 패키지는 없어요.

```bash
cp .env.example .env    # 비밀번호와 봇 토큰을 적어 주세요
npm start               # http://localhost:3000
```

휴대폰 브라우저로 접속한 뒤 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있어요.

기록은 `data/db.json` 파일 하나에 저장됩니다. 이 파일만 잘 보관하면 돼요.

### Docker

```bash
docker build -t minhan-diary .
docker run -d -p 3000:3000 -v $PWD/data:/data --env-file .env minhan-diary
```

> 기록을 파일에 저장하는 서버라서, 파일이 남지 않는 서버리스 호스팅(Vercel 등)에는 맞지 않아요. 집 PC, NAS, 라즈베리파이, 디스크가 붙는 클라우드 서버(Fly.io, Railway 등)에 올려 주세요.

## 텔레그램 봇 연결

1. 텔레그램에서 **@BotFather** 에게 `/newbot` 을 보내 봇을 만들고 토큰을 받습니다.
2. `.env` 에 `TELEGRAM_BOT_TOKEN=받은토큰` 을 적고 서버를 다시 켭니다.
3. 가족 단체방의 모든 대화를 받으려면 BotFather 에서 `/setprivacy` → 봇 선택 → **Disable** 을 해 주세요. (그 뒤에 봇을 방에 초대해야 적용돼요. 이미 초대했다면 내보냈다가 다시 초대하세요.)
4. 방에서 `/id` 를 보내 대화방 ID를 확인하고, `.env` 의 `TELEGRAM_ALLOWED_CHATS` 에 적어 두면 다른 방의 메시지는 받지 않습니다.

봇은 서버에서 텔레그램에 직접 접속하므로(롱 폴링) 서버 주소를 외부에 공개하지 않아도 됩니다.

## 보안

- `APP_PASSWORD` 를 설정하면 앱을 열 때 가족 비밀번호를 물어봅니다. 인터넷에 공개한다면 꼭 설정하고 HTTPS 를 쓰세요.
- 캡쳐 글자 읽기는 휴대폰 브라우저 안에서 처리되며, 사진이 외부 서버로 보내지지 않습니다. (글자 읽기 프로그램과 한글 사전은 처음 한 번 인터넷에서 받아 옵니다.)
