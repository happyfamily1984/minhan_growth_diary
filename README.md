# 민한이 성장일기 👶💬🌱

민한이(2016년 2월 22일 오전 11시 55분생)가 **한 말**과 **한 일**을 날짜별로 기록하는 안드로이드 앱입니다.
서버 없이 폰 안에 저장되고, 인터넷이 없어도 동작합니다.

## 기능

- **오늘**: 탄생 며칠째인지(태어난 날 = 1일째, 백일 = 100일째), 만 나이, 태어난 뒤 흐른 시간, 다음 기념일 D-day
- **쓰기**: 💬 한 말 / 🌱 한 일 중에 고르고, 날짜·상황 메모·시간을 함께 적어요.
- **달력**: 기록이 있는 날에 점이 찍히고, 날짜를 누르면 그날 기록이 보여요.
- **지난해 오늘**, **찾기**(단어 검색)
- **가져오기**: 텔레그램 대화를 넣으면 날짜를 찾아 그 날짜에 넣어 줘요.
  - **복사해서 붙여넣기**: 보낸 사람, 시간, 읽음 표시(✓✓), `(편집됨)`, `[사진]` 같은 것은 빼고 **날짜와 내용만** 넣어요.
    `엄마, [13.11.2026 18:20]` · `[13.11.26 18:20] 엄마: 내용` · `11월 13일` 같은 날짜 줄을 알아봐요.
  - **캡쳐 사진**: 사진 속 글자를 폰 안에서 읽어서(한글 OCR) 말풍선마다 나눠요. 캡쳐의 날짜 표시(예: `11월 12일`)를 날짜로 쓰고, 날짜가 안 보이면 사진 만든 날이나 직접 고른 날짜로 넣어요.
  - **공유하기**: 텔레그램이나 갤러리에서 **공유 → 민한이 성장일기**를 고르면 바로 가져오기 화면으로 열려요.
  - 넣기 전에 민한이가 한 말·한 일만 체크하고, 글자·날짜·종류(한 말/한 일)를 고칠 수 있어요.
- **백업 / 되살리기**: 기록은 폰 안에만 있으니 가끔 백업 파일을 만들어 구글 드라이브나 카톡 나에게 보내기로 보관하세요.

## 설치 (안드로이드)

1. `민한이성장일기.apk` 파일을 폰에 받아서 누릅니다.
2. "출처를 알 수 없는 앱 설치"를 허용해 달라고 하면 허용합니다.

## 개발

```bash
npm install
npm test            # 날짜 계산, 붙여넣기/캡쳐 글 나누기 테스트
npm run serve       # 컴퓨터 브라우저에서 미리 보기 (http://localhost:5173)
```

### APK 만들기

Android SDK(`ANDROID_HOME`)와 JDK 21이 필요합니다.

```bash
npm run android:sync
cd android && ./gradlew assembleRelease   # android/app/build/outputs/apk/release/app-release.apk
```

**서명 키**: 업데이트 APK를 덮어 설치하려면 처음과 같은 키로 서명해야 해요.
키 파일(`minhan-release.keystore`, `keystore.properties`)은 저장소에 올리지 않았으니 잘 보관하고, 다시 빌드할 때 `android/` 폴더에 넣어 주세요.
키가 바뀌면 앱을 지우고 다시 깔아야 하는데, 그러면 기록이 지워지니 **먼저 백업**하세요.

## 구조

```
www/           앱 화면 (HTML/CSS/JS)
  app.js       화면 동작
  store.js     기기 안 저장 (IndexedDB)
  parse.js     붙여넣은 글 / 캡쳐 글 → 날짜별 기록 후보
  ocr-prep.js  캡쳐를 글자 읽기 좋게 흑백으로 바꾸기
  shared.js    탄생 일수, 만 나이 계산
android/       안드로이드 앱 (Capacitor)
scripts/       OCR 도구 복사, 미리 보기 서버
```
